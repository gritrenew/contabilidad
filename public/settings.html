Cómo funciona

Esta app se conecta de solo lectura a la vista configurada arriba y agrega los movimientos por Sociedad, N° de cuenta, año y mes usando el campo Importe divisa-adicional (Additional_Currency_Amount). El Dashboard y el Reporte consumen ese mismo dato agregado.

Modelo híbrido de configuración: lo que guardes aquí se cifra y queda en este servidor para uso diario. En producción (Azure Web App), puedes fijar las mismas variables como DB_SERVER, DB_PORT, DB_DATABASE, DB_USER, DB_PASSWORD, DB_VIEW, DB_ENCRYPT, DB_TRUST_CERT en Application Settings de Azure — esas siempre ganan sobre lo guardado aquí.
